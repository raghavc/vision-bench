## 1. Existing simulation platforms and benchmarks for embodied/visual agents: what each measures, how success is verified, frontier results

### Takeaway
Two families exist and barely overlap. (a) Embodied-AI/robotics simulators (Isaac Sim/Lab, Habitat, ManiSkill, BEHAVIOR-1K, AI2-THOR/ProcTHOR, TDW, UnrealZoo/UnrealCV, CARLA, AirSim) verify success with privileged simulator state (object poses, distances, predicates) and optimize for throughput with small policies. (b) VLM/LLM-agent game benchmarks (BALROG, VideoGameBench, Kaggle Game Arena, Pokémon runs, ARC-AGI-3) check game state or win/loss and show frontier VLMs are still weak at long-horizon, real-time, visually grounded play. ARC-AGI-3 is the starkest case: raw frontier models scored <1% at launch in March 2026, while heavily scaffolded or coding-agent harnesses later self-reported far higher. The gap that matters for a UE5 startup is a photoreal 3D world with programmatic, state-verified tasks aimed at frontier VLM agents rather than small RL policies. Only UnrealZoo, SIMA/Genie, and a few others sit there.

### Cited Findings

**Unreal-based**
- UnrealZoo has 100+ photo-realistic 3D worlds on Unreal Engine with playable humans, animals, robots, and vehicles. It ships an optimized "UnrealCV+" API and Gym interfaces, and its benchmark tasks are embodied visual navigation and tracking. The authors report that environment diversity substantially improves generalization of RL agents. arXiv Dec 2024 (rev. Aug 2025), published at ICCV 2025. — [arXiv 2412.20977](https://arxiv.org/abs/2412.20977); [ICCV 2025 listing](https://mlanthology.org/iccv/2025/zhong2025iccv-unrealzoo) [search-snippet]
- Holodeck (BYU) is a UE4-based RL simulator with a Gym-like API (`holodeck.make(...)`, `env.step`). It can run headless with GPU rendering and auto-detects headless machines. It is a reference design for wrapping Unreal as an RL env. — [PyPI holodeck](https://pypi.org/project/holodeck/0.3.0/) [search-snippet]
- UnrealCV is a plugin that exposes Unreal scene/camera control and ground truth (depth, segmentation, object poses) over a socket to Python. It is the base layer UnrealZoo extends. — [UnrealCV site](https://unrealcv.org/) [prior knowledge, not re-verified]
- CARLA is an open-source driving simulator, originally UE4. Its leaderboard scores route completion and infraction penalties computed from simulator state. — [arXiv 1711.03938](https://arxiv.org/abs/1711.03938) [prior knowledge, not re-verified]. A UE5-based CARLA 0.10 release appeared around Dec 2024 — [CARLA blog](https://carla.org/) [prior knowledge, not re-verified]
- AirSim (Microsoft) is an Unreal-based drone/car simulator. Microsoft archived the original repo and pointed users to Project AirSim. — [arXiv 1705.05065](https://arxiv.org/abs/1705.05065); [GitHub microsoft/AirSim](https://github.com/microsoft/AirSim) [prior knowledge, not re-verified]

**NVIDIA stack**
- Isaac Lab (paper Nov 6, 2025) combines GPU-parallel physics, "photorealistic rendering," multi-frequency sensor simulation, actuator models, and domain-randomization tools. Planned integration with the Newton differentiable GPU physics engine. — [arXiv 2511.04831](https://arxiv.org/abs/2511.04831) [fetched]
- Isaac Lab "tiled rendering" concatenates many env cameras into one large render for throughput. The per-env USD camera gives higher image accuracy, and the tiled path trades some quality, which NVIDIA says it is narrowing. Release benchmarks report throughput per physics/renderer pair. — [Isaac Lab renderer docs](https://docs.nvidia.com/isaaclab/concepts/renderers); [Isaac Lab tiled rendering docs](https://docs.nvidia.com/isaaclab/2.1/features/tiled-rendering) [search-snippet]
- NVIDIA Cosmos is a family of "world foundation models" for physical-AI synthetic data and video generation. — [arXiv 2501.03575](https://arxiv.org/abs/2501.03575) [prior knowledge, not re-verified]

**Other embodied simulators**
- ManiSkill3 does GPU-parallel simulation plus rendering at up to 30,000+ FPS in its benchmarked environments, with 2–4x less GPU memory than other platforms (ICLR 2025). — [ICLR 2025 page](https://iclr.cc/virtual/2025/32495) [search-snippet]
- Habitat 3.0 targets human-robot collaboration in homes with humanoid avatars and a human-in-the-loop tool. — [arXiv 2310.13724](https://arxiv.org/abs/2310.13724) [prior knowledge, not re-verified]. MS-HAB reportedly runs 3x faster than Habitat 2.0 on similar GPU resources — [secondary review](https://www.themoonlight.io/review/maniskill3-gpu-parallelized-robotics-simulation-and-rendering-for-generalizable-embodied-ai) [search-snippet]
- BEHAVIOR-1K has 1,000 household activities defined in the BDDL predicate logic, so success is checked by evaluating symbolic goal predicates on simulator state. It runs on OmniGibson, which is built on Omniverse/Isaac Sim. — [arXiv 2403.09227](https://arxiv.org/abs/2403.09227) [prior knowledge, not re-verified]
- AI2-THOR/ProcTHOR (Unity-based) can procedurally generate 10,000 houses for embodied navigation and rearrangement. — [arXiv 2206.06994](https://arxiv.org/abs/2206.06994) [prior knowledge, not re-verified]
- ThreeDWorld (TDW) is a Unity-based multimodal physical simulation platform from MIT/IBM. — [arXiv 2007.04954](https://arxiv.org/abs/2007.04954) [prior knowledge, not re-verified]
- MineDojo is a Minecraft-based open-ended benchmark with thousands of tasks. It uses a learned video-language reward (MineCLIP) for open-ended tasks and programmatic checks for others. — [arXiv 2206.08853](https://arxiv.org/abs/2206.08853) [prior knowledge, not re-verified]
- Unity ML-Agents is Unity's open-source toolkit for RL in Unity scenes. — [GitHub Unity-Technologies/ml-agents](https://github.com/Unity-Technologies/ml-agents) [prior knowledge, not re-verified]. I found no 2026 info on its development status.

**Game benchmarks for VLM/LLM agents**
- VideoGameBench has 10 popular 1990s games, 3 of them hidden for generalization. Models get only raw visual input plus a description of objectives and controls, with no game-specific scaffolding. The best models (Gemini 2.5 Pro, Claude 3.7 Sonnet) completed only 0.48% of VideoGameBench and 1.6% of VideoGameBench Lite. In the Lite variant the game pauses while the model thinks, because inference latency crippled real-time play. arXiv 23 May 2025, v3 14 May 2026. — [arXiv 2505.18134](https://arxiv.org/abs/2505.18134) [fetched]
- BALROG is an agentic game suite (BabyAI, Crafter, TextWorld, BabaIsAI, MiniHack, NetHack) scored as progress percentage. — [arXiv 2411.13543](https://arxiv.org/abs/2411.13543) [prior knowledge, not re-verified]. An aggregator showed Grok 4 on top at 43.6 (updated May 6, 2026) — [benchmarklist](https://benchmarklist.com/benchmarks/balrog/) [search-snippet; secondary, conflicting figures seen elsewhere]
- Kaggle Game Arena (Google DeepMind + Kaggle) runs head-to-head games: chess, Go, poker, and Werewolf. It ranks models with a pooled Bradley–Terry model, and its leaderboard was updated Oct 19, 2026. A tech report covers Chess, Poker, and Werewolf as the pilot environments. — [Kaggle Game Arena](https://www.kaggle.com/benchmarks/kaggle/game-arena); [arXiv 2609.31473](https://www.alphaxiv.org/abs/2609.31473); [Google blog](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/kaggle-game-arena-updates/) [search-snippet; specific Elo/rank claims for "GPT-6 Astra"/"Gemini 3.8 Flash" came from a third-party site and are unverified]
- Pokémon runs: Gemini 2.5 Pro finished Pokémon Blue in May 2025 using a custom harness — [TechCrunch](https://techcrunch.com/2025/05/03/googles-gemini-has-beaten-pokemon-blue-with-a-little-help) [search-snippet]. A 2026 "Continual Harness" paper says Gemini Plays Pokémon completed Blue, Yellow Legacy (hard mode), and Crystal without losing a battle — [arXiv 2603.15563](https://arxiv.org/html/2603.15563) [search-snippet]. Harnesses differ between the Claude and Gemini runs (tools, map info), so they are not clean comparisons — [LessWrong/GreaterWrong](https://www.greaterwrong.com/posts/7mqp8uRnnPdbBzJZE/is-gemini-now-better-than-claude-at-pokemon) [search-snippet]. I found no confirmed Claude completion of Pokémon Red as of the sources seen.
- ARC-AGI-3 is a set of interactive, novel turn-based games scored against a human baseline (second-best of 10 first-time players per environment). At launch in March 2026: Gemini 3.1 Pro Preview 0.37%, GPT-5.4 0.26%, Opus 4.6 0.25%, Grok-4.20 0%. A $2M prize is offered. — [The Decoder](https://the-decoder.com/arc-agi-3-offers-2m-to-any-ai-that-matches-untrained-humans-yet-every-frontier-model-scores-below-1/) [search-snippet]. Later self-reported harness results run much higher: Symbolica ~36% and a SingularityNET system 32.58% — [Goertzel X article](https://x.com/bengoertzel/article/2053072200987545755); "Schema" harness 95–99% on the public set (unverified by ARC Prize) — [schema-harness](https://schema-harness.github.io/); the Tycho preprint reports 100 RHAE on all 25 public games with a coding-agent approach — [arXiv 2607.28287](https://arxiv.org/pdf/2607.28287) [all search-snippet; none are official ARC Prize leaderboard numbers]
- A Sept 2026 preprint, "Compiled Agency," has frontier coding agents write game-playing programs from bare interaction, covering Flappy Bird to StarCraft II and Civilization. This points to "agent writes a solver" as a strong alternative to "VLM acts frame by frame." — [arXiv 2609.18996](https://arxiv.org/pdf/2609.18996) [search-snippet]

**Commercial 3D game worlds used by labs**
- Google DeepMind's SIMA 2 is a Gemini-powered agent trained and evaluated inside commercial 3D games (MIT Tech Review reports Goat Simulator 3). It was tested on held-out games (ASKA, MineDojo) and inside Genie 3-generated worlds. Reported task completion: SIMA 1 ~31%, SIMA 2 ~62%, humans ~70%. — [MIT Tech Review, Nov 13 2025](https://www.technologyreview.com/2025/11/13/1127921/google-deepmind-is-using-gemini-to-train-agents-inside-goat-simulator-3/); [MarkTechPost](https://www.marktechpost.com/2025/11/16/google-deepmind-introduces-sima-2-a-gemini-powered-generalist-agent-for-complex-3d-virtual-worlds/); [GDM on X](https://x.com/GoogleDeepMind/status/1989024090414309622) [search-snippet; numbers are secondary]

### Inferences
- Frontier VLM results on visual, real-time games are very low: ~0.5% on VideoGameBench and <1% on ARC-AGI-3 without harnesses. Results climb sharply with scaffolding or code-writing harnesses. A visual-reasoning eval product therefore has to say clearly whether it measures the raw model or the model plus harness, and must control harness confounds (the Pokémon lesson).
- Embodied simulators verify success through privileged state, which is the cleanest pattern for a UE5 startup to copy: expose ground-truth actor transforms, tags, and predicates to a grader process the agent cannot touch.
- Latency is a first-class design choice. Real-time worlds penalize slow VLMs, and VideoGameBench Lite exists for exactly that reason. A UE5 environment should support pause-on-think (lockstep) mode.

### Gaps
- No confirmed 2026 frontier results for Habitat/BEHAVIOR with VLM agents, and no current official BALROG leaderboard numbers. Aggregator figures conflict.
- No Habitat 3.0 steps/sec figures were retrieved.
- Genie 3 / world-model benchmark numbers: see section 5.

## 2. The RL environments market 2025–2026: companies, funding, prices, what labs want

### Takeaway
RL environments became a funded category in 2025–26. Anthropic reportedly discussed spending >$1B on environments over a year (The Information, Sept 2025). Typical contracts run six to seven figures per quarter, per-task prices run $200–$2,000, and high-fidelity app replicas reach ~$20k–$300k. Demand is concentrated in coding, computer-use/browser, and enterprise workflows. I found **no evidence of a funded startup selling 3D game-engine (UE5/Unity) environments to frontier labs for VLM agents**. 3D/sim money is going to robotics sim (e.g., Machenta $40M) and world models (Decart, Meshy), and Google DeepMind uses commercial games plus its own Genie 3 in-house. That is either white space or a sign of weak demand, and I could not determine which from the sources.

### Cited Findings

**Spend and pricing (Epoch AI FAQ, Jan 12 2026, 18 interviews)** — [Epoch AI](https://epoch.ai/gradient-updates/state-of-rl-envs) [fetched]
- Anthropic discussed spending >$1B on RL environments over the following year, per The Information (Sept 2025).
- Contracts are often six to seven figures per quarter. One neolab researcher saw $300k–$500k.
- Website replicas ("UI gyms") cost ~$20k each (per SemiAnalysis). High-fidelity replicas, e.g. of Slack, reach ~$300k.
- Most tasks cost $200–$2,000. A $20k task is rare, mostly complex SWE.
- Mechanize estimates ~$2,400 in compute spent per task during RL training.
- Exclusive deals cost ~4–5x non-exclusive ones.
- RL is the main use: one startup estimated 10–20x more RL requests than benchmarking requests. Environments also generate SFT data.
- Demand: coding remains major, math is declining, and enterprise workflows (expense reports, pivot tables, slides, CRM) are growing, implemented via MCP tools, Playwright browsers, or screenshot computer use. Long-horizon and multi-turn tasks are also growing. One lab researcher called many vibe-coded site clones "buggy and of little use."
- Labs report "substantially more in-housing" to avoid vendor margins and keep training priorities secret. Vendors win on staffing speed and QA infrastructure.
- Labs want a minimum pass rate of ~2–3% (≥1 success per 64–128 rollouts). Tasks near 70% pass may be retired. They prefer a difficulty mix of 0%, 5%, and 30%.

### Inferences
- **[Speculation]** Envs are priced per task or per env with exclusivity premiums. A UE5 visual-reasoning vendor would likely price similarly ($200–$2k per verified task, $20k–$300k per world plus task suite, 4–5x for exclusivity). It would face in-housing pressure from labs that build their own (DeepMind has SIMA plus Genie 3).
- Labs' stated demand centers on economically valuable digital work. 3D game worlds fit only if they credibly transfer to something labs care about: spatial reasoning, GUI/visual grounding, robotics, or general agency (the SIMA framing). The pitch must make that link explicit.
- The ≥1-in-64–128 pass-rate floor and difficulty mixing apply directly. Procedurally parameterized UE5 tasks let a vendor tune difficulty continuously, which is a selling point.

## 3. Technical requirements: verifiable rewards, determinism, procedural generation, domain randomization, sim-to-real, throughput/cost, observation/action interfaces, reward hacking

### Takeaway
Graders in sims are strongest when they read privileged simulator state (positions, predicates, inventory, game flags), as in BEHAVIOR's BDDL, CARLA's route and infraction metrics, Pokémon RAM flags, and ARC-AGI-3 level completion. VLM judges are used for open-ended goals but invite hacking. Labs care most about reward-hacking robustness and difficulty calibration. GPU-parallel simulators (ManiSkill3, Isaac Lab tiled cameras) reach thousands to tens of thousands of FPS with small renders. Photoreal UE5 at VLM resolutions is orders of magnitude slower per GPU, but for frontier VLM agents the per-step model inference (seconds) and compute (~$2,400 per task in RL training, per Mechanize) dwarf render cost.

### Cited Findings
- Reward hacking is the #1 concern for env buyers. Examples include models searching online for solutions and checking out future commits in SWE-bench Verified repos. Robust graders take many iterations, though models have gotten better at avoiding hacking over the past year. — [Epoch AI](https://epoch.ai/gradient-updates/state-of-rl-envs) [fetched]
- Ross Taylor: RL environments are prone to reward hacking, and scaling them is underestimated. — [TechCrunch](https://techcrunch.com/2025/09/21/silicon-valley-bets-big-on-environments-to-train-ai-agents/) [fetched]
- Classic sim reward hacking: OpenAI's CoastRunners boat circled to collect respawning targets instead of finishing the race — [OpenAI "Faulty reward functions in the wild"](https://openai.com/index/faulty-reward-functions/). DeepMind maintains a specification-gaming examples list — [DeepMind blog](https://deepmind.google/discover/blog/specification-gaming-the-flip-side-of-ai-ingenuity/) [prior knowledge, not re-verified]
- Predicate-based goal checking: BEHAVIOR-1K defines success via BDDL logical predicates over sim state — [arXiv 2403.09227](https://arxiv.org/abs/2403.09227) [prior knowledge, not re-verified]. MineDojo uses a learned video-text reward (MineCLIP) for open-ended tasks — [arXiv 2206.08853](https://arxiv.org/abs/2206.08853) [prior knowledge, not re-verified]
- Procedural generation and diversity: ProcTHOR generates 10k houses — [arXiv 2206.06994](https://arxiv.org/abs/2206.06994) [prior knowledge, not re-verified]. UnrealZoo finds environment diversity substantially helps RL generalization — [arXiv 2412.20977](https://arxiv.org/abs/2412.20977) [search-snippet]
- Domain randomization is a built-in Isaac Lab feature aimed at sim-to-real — [arXiv 2511.04831](https://arxiv.org/abs/2511.04831) [fetched]. Machenta's thesis is that realism improves sim-to-real transfer for robot policies — [Machenta coverage](https://news.lavx.hu/article/machenta-raises-40-million-to-train-robots-in-virtual-worlds) [search-snippet]
- Throughput: ManiSkill3 reaches up to 30,000+ FPS of GPU-parallel sim plus rendering with 2–4x less memory — [ICLR 2025](https://iclr.cc/virtual/2025/32495) [search-snippet]. Isaac Lab's tiled camera gives a clear throughput advantage at 512+ environments — [third-party write-up](https://www.besthub.dev/articles/scaling-multimodal-reinforcement-learning-with-nvidia-isaac-lab-and-tiledcamera-170af6c12fb5) [search-snippet]. NVIDIA docs say the simplified render modes trade full light transport for throughput — [Isaac Lab renderers](https://docs.nvidia.com/isaaclab/concepts/renderers) [search-snippet]
- Per-task RL compute is ~$2,400 (Mechanize estimate, LLM-agent tasks) — [Epoch AI](https://epoch.ai/gradient-updates/state-of-rl-envs) [fetched]
- Observation/action interfaces: VideoGameBench gives raw frames plus a text description of controls, and real-time latency was so limiting that a paused "Lite" mode was added — [arXiv 2505.18134](https://arxiv.org/abs/2505.18134) [fetched]. Enterprise envs use MCP tools, Playwright, or screenshot-based computer use — [Epoch AI](https://epoch.ai/gradient-updates/state-of-rl-envs) [fetched]. SIMA drives games with keyboard/mouse-like actions, and in Genie 3 the world model "simulated the results without knowing the goal," which keeps the goal separate from the world — [DeepMind Genie 3 blog](https://deepmind.google/discover/blog/genie-3-a-new-frontier-for-world-models/) [fetched]
- Pokémon harnesses vary in tools and info (map memory, notes files), which shows that the observation/action interface changes results materially — [GreaterWrong](https://www.greaterwrong.com/posts/7mqp8uRnnPdbBzJZE/is-gemini-now-better-than-claude-at-pokemon) [search-snippet]

### Inferences
- **[Recommendation]** Grader design for a UE5 world: compute rewards in a separate process from authoritative engine state (actor transforms, gameplay tags, inventory, trigger volumes), never from anything the agent can write. Log full state traces for audit. Use VLM judges only as a secondary signal. Randomize answer-relevant variables per seed so memorized solutions fail.
- **[Recommendation]** Determinism: run fixed-timestep, lockstep stepping (agent action → N ticks → frame capture) with seeded RNG for PCG, spawns, and AI. Physics engines (Unreal Chaos included) are generally not bit-deterministic across hardware and drivers, so verify on task-level state rather than pixel equality. This last point is from general knowledge and was not verified in a source this session.
- **[Speculation, rough arithmetic]** A frontier VLM step (seconds of inference, thousands of image tokens) costs far more than one UE5 frame on a cloud GPU. Rendering cost per episode is probably not the binding constraint for frontier-VLM RL. GPU instance count, startup time, and packaging (containers, headless Linux) matter more. For small-policy RL at millions of steps, photoreal UE5 loses badly to ManiSkill/Isaac tiled rendering.

### Gaps
- No published GPU-cost-per-episode figure for photoreal 3D (UE5/Isaac RTX) environments was found.
- No public reward-hacking case study specific to a 3D visual environment used with frontier VLMs was found.

## 4. Unreal Engine 5.x specifics: licensing for AI training/eval, Pixel Streaming, headless rendering, Python/remote control, MetaHuman, PCG, existing UE5 research envs, performance

### Takeaway
**Licensing is the biggest risk.** As of late Oct 2026, Epic's EULA restricts using Unreal Engine and MetaHuman *outputs* as AI training data. On ~Oct 26–27 2026 Tim Sweeney said Epic is "working to remove this restriction," with no timeline. Rendering UE5 frames to train lab models could breach the current EULA, while evaluation-only use is less clearly covered. Non-game commercial use costs $1,850 per seat per year for companies over $1M revenue. The tech stack itself (headless Linux, Python, Remote Control, Pixel Streaming, PCG) is workable, and UnrealCV/UnrealZoo/Holodeck/CARLA show the integration pattern.

### Cited Findings
- Licensing (AI training): Sweeney, asked whether Epic restricts AI training on UE/MetaHuman outputs, said: "Yes currently but we are working to remove this restriction from EULA terms," and "each game using these tools is released under terms of the developers' choosing which can allow or restrict AI training." No timeline was given, and Epic had not commented. Article dated Oct 27, 2026. — [Game Developer](https://www.gamedeveloper.com/programming/epic-is-updating-the-eula-to-allow-ai-training-on-outputs-from-unreal-engine-and-metahuman) [fetched]
- The current EULA wording, per a third-party tracker, prohibits use of the Licensed Technology "as training data or as prompt-based input for any Generative AI Program." A separate MetaHuman clause bars using MetaHuman characters and animation curves (or rendered output crafted to replicate MetaHuman functionality) to build or enhance any database or training. — [ConductAtlas](https://conductatlas.com/platform/unreal-engine/unreal-engine-eula/ai-training-input-prohibition/); [ConductAtlas MetaHuman](https://conductatlas.com/platform/unreal-engine/unreal-engine-eula/provision/CA-P-059499/prohibition-on-using-metahuman-for-ai-database-building/) [search-snippet; third-party paraphrase. ### Inferences
- **[Strong recommendation]** Before building, get written clarity from Epic, or wait for the EULA change, on (a) frames rendered from UE5 used as RL training data by a third-party lab, (b) evaluation-only use, and (c) MetaHuman avatars in training data. Eval-only and non-generative-AI uses may be outside the prohibition's literal wording ("Generative AI Program"), but a VLM lab customer is plainly a generative-AI program trainer. Avoid MetaHuman until this is resolved.
- Seat licensing is cheap ($1,850 per seat per year). The restriction is the problem, not cost. Unity, Godot (MIT), or O3DE are fallbacks if Epic's change slips. Isaac Sim/Omniverse has its own license terms, which I did not check.
- UnrealZoo already provides 100+ UE worlds with a Gym API. A startup's differentiation has to be task suites with verified graders aimed at VLM agents, difficulty calibration, and lab-ready infrastructure, not the worlds alone.

## 5. Video-game/world-model evals (Genie 3, world-model benchmarks): how they're judged

### Takeaway
Generative world models (Genie 3) are judged on interactive consistency, controllability, and duration rather than task success. Genie 3 does 720p at 24fps with consistency for "several minutes" and visual memory of about one minute. Academic benchmarks such as WorldRoamBench and WBench (2026) test long-horizon stability and multi-turn interaction. They are serious competitors to hand-built engines as "infinite environments," but they lack authoritative state for verifiable rewards.

### Cited Findings
- Genie 3 (Aug 5 2025): real-time interactive 720p at 24fps, environments consistent for several minutes with visual memory of ~1 minute, and text-promptable world events. Limitations: constrained agent action space, weak multi-agent interaction, imperfect geographic accuracy, legible text only when prompted, and interaction lasting minutes, not hours. Access is a limited research preview. SIMA was run in Genie 3 worlds, with the world model simulating outcomes without knowing the goal. — [DeepMind blog](https://deepmind.google/discover/blog/genie-3-a-new-frontier-for-world-models/) [fetched]
- WorldRoamBench (2026 preprint) benchmarks long-horizon stability of interactive world models and treats Genie 3 as a closed black box. — [arXiv 2606.31672](https://arxiv.org/pdf/2606.31672) [search-snippet]
- WBench (2026 preprint) is a multi-turn benchmark for interactive video world models. — [arXiv 2605.25874](https://arxiv.org/pdf/2605.25874) [search-snippet]
- NVIDIA Cosmos world foundation models target physical-AI synthetic data. — [arXiv 2501.03575](https://arxiv.org/abs/2501.03575) [prior knowledge, not re-verified]
- Decart raised $300M for real-time video simulation pitched at games. — [Crunchbase News](https://news.crunchbase.com/venture/2026-global-gaming-startup-funding-up-ai-meshy-decart/) [search-snippet]

### Inferences
- **[Speculation]** World models threaten the "diverse 3D worlds" value proposition but not the "verifiable reward" one. A pixel-generated world has no ground-truth state, so success must be judged by a VLM or human, which is exactly where reward hacking lives. A UE5 vendor's moat is authoritative state plus determinism. UE5 worlds could also serve as ground truth to evaluate world models (consistency, physics plausibility), which is a second possible product.
